Research

DELL Computers Project — Jan 2026/present

I develop an LLM-based agent that reviews code changes and orchestrates multi-step workflows to enrich contextual information and resolve security vulnerabilities directly within production pipelines.

ANATEL Project — Mar 2025/Sep 2026

I compare large language models against traditional NLP and machine learning methods to classify legal texts into procedural stages, and deploy the resulting pipeline into production.

UFCG Dropout Project — Jun 2024/Feb 2025

I built explainable machine learning models to predict student dropout, combining SHAP and LIME with open-source LLMs to translate predictions into plain-language explanations for university staff.

StopSpeaking — 2021/2022

As part of my technical studies at IFPB, I co-developed a hardware device with embedded sensors to measure and alert on excessive noise levels in shared environments such as classrooms.
